# Direct Developer ID zip, not Mac App Store

Other Macs should open UmpaDumpa without the developer’s Apple ID. V1 ships a notarized zip of a Developer ID–signed `.app` (script `scripts/distribute-macos.sh`), not the Mac App Store.

Rejected for now: App Store (review, sandbox, more process than a handful of colleagues) and “right-click Open” on an unsigned build (looks untrusted).
